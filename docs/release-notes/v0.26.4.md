# CineUSB 0.26.4

Esta versión incorpora las mejoras visuales de la biblioteca USB de la PR #30.

- Pantalla de ajustes unificada de dos columnas, con descripciones de cada opción y navegación con el mando LG Magic Remote.
- Duración y calidad de vídeo visibles en las tarjetas de películas y episodios, a partir de los metadatos reales de cada archivo.
- Reconocimiento de resoluciones cinematográficas recortadas, como 3840×1608 y 4096×1716, con la etiqueta 4K UHD, sin confundir 1440p con 4K.
- Nueva confirmación visual de expulsión segura de USB: progreso, éxito animado y aviso de error con reintento.

Se mantienen la reanudación de reproducción, los favoritos, las pistas de audio y subtítulos y la compatibilidad USB de las versiones anteriores. La expulsión continúa dependiendo de que webOS confirme el desmontaje.
