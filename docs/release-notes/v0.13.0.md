# CineUSB 0.13.0

Esta versión mejora la lectura local de películas desde discos USB, especialmente en sistemas NTFS. Si el controlador de archivos rechaza una lectura posicional, CineUSB reintenta ese mismo tramo mediante desplazamiento y lectura convencional, sin modificar el archivo.

El reproductor identifica por separado los fallos al abrir el contenedor multimedia y los fallos al analizar sus pistas. Cuando alguna de estas etapas falla, el registro de CineUSB conserva el código de error de FFmpeg para facilitar el diagnóstico.

Se conservan la navegación por carpetas, el manejo del mando LG y el filtrado visual de carpetas de mantenimiento de las versiones anteriores.

**Pendiente de comprobar en la LG OLED C1:** que el archivo que mostraba «No se pudo reconocer el formato del vídeo» se pueda analizar y reproducir. El mensaje anterior no demuestra por sí solo que el controlador NTFS sea la causa: un contenedor dañado o un problema del lector FFmpeg todavía podrían impedir la reproducción.
