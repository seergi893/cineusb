# CineUSB 0.18.0

La biblioteca USB estrena carátulas ilustradas para películas, series, carpetas y discos. Al abrir CineUSB, la pantalla de inicio te saluda según la hora del televisor.

El nuevo icono de CineUSB combina una tira de cine con un conector USB. Para instalar la versión, abre CineUSB en Homebrew Channel y pulsa **Update**.

SHA-256 del IPK `__IPK_SHA256__`.
