# CineUSB 0.22.0

Las opciones de vídeo y las confirmaciones de borrado y expulsión tienen iconos y un foco más visible. El arranque muestra el icono de CineUSB.

En **Ajustes** puedes dar prioridad al audio en español. Al abrir un vídeo, CineUSB busca primero castellano de España cuando la pista está identificada. Puedes cambiar de pista durante la reproducción.

Dentro de una carpeta del USB, usa **Seleccionar** para marcar varias subcarpetas y eliminarlas con su contenido tras confirmar.

SHA-256 del IPK `__IPK_SHA256__`.
