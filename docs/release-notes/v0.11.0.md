# CineUSB 0.11.0

Esta versión corrige la publicación de actualizaciones de CineUSB: el instalador usa un número de versión nuevo para que Homebrew Channel pueda distinguir el paquete de la versión anterior.

El explorador USB incorpora compatibilidad adicional para los códigos de las flechas y del botón OK del mando LG cuando webOS no proporciona un código de tecla convencional. También incluye las correcciones anteriores de detección de montajes USB y de activación mediante el Magic Remote.

La interfaz sigue siendo un explorador USB independiente: reutiliza componentes visuales de PlxNative, pero todavía no utiliza su sistema completo de navegación y enfoque.

**Pendiente de comprobar en una LG física:** que el botón OK abra el disco y las carpetas, que la navegación funcione y que la reproducción sea compatible. La compilación no demuestra por sí sola el funcionamiento en el televisor.

SHA-256 del IPK `__IPK_SHA256__`.
