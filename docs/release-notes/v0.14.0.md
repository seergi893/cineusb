# CineUSB 0.14.0

Corrige la detección de unidades USB dentro del aislamiento (jail) de webOS, donde CineUSB podía listar directorios pero recibir `EIO (os error 5)` al leer los archivos, incluso desde el primer byte.

La app ahora intenta preparar periódicamente los montajes USB de solo lectura mediante el servicio root de Homebrew, aunque la exploración de carpetas funcione. El acceso alternativo `/tmp/cineusb-volumes` aparece primero en el selector de volúmenes si ha podido montarse. Si el servicio no está disponible, se mantienen las rutas que la app ya podía ver y se registra el error de sincronización.

No se cambia el contenido del USB, no se repara NTFS y no se alteran los códecs.

**Validación pendiente:** probar en la LG OLED C1 del usuario que el puente de lectura se monta y que `Crash.mkv` comienza a reproducirse. Se ha confirmado por SSH que root puede leer el archivo, mientras el proceso CineUSB devuelve EIO; no se ha verificado todavía el resultado de este cambio en el dispositivo.

SHA-256 del IPK `__IPK_SHA256__`.
