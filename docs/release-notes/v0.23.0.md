# CineUSB 0.23.0

La biblioteca aprovecha mejor la pantalla con filas más equilibradas, una barra compacta y un foco más visible. **Biblioteca** vuelve a la raíz del USB actual.

Las opciones de vídeo muestran el formato HDR, el tamaño y la duración cuando se pueden leer del archivo. CineUSB obtiene esos datos directamente del USB en segundo plano.

SHA-256 del IPK `__IPK_SHA256__`.
