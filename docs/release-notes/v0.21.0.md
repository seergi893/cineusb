# CineUSB 0.21.0

CineUSB guarda el idioma y la opción de subtítulos forzados en sus propios ajustes. Si activas los forzados, CineUSB busca una pista compatible al abrir cada vídeo.

Al pulsar OK sobre un vídeo aparece un menú con **Reproducir** y **Eliminar archivo**. El borrado tiene una confirmación aparte con el nombre del fichero.

SHA-256 del IPK `__IPK_SHA256__`.
