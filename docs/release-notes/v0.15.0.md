# CineUSB 0.15.0

CineUSB abre el archivo de vídeo en solo lectura y entrega el descriptor a FFmpeg para identificar el contenedor y reproducirlo. Si falla el acceso directo, Homebrew Channel con root puede abrir el archivo USB fuera del aislamiento de la aplicación y pasarle el descriptor.

Los errores de apertura y de análisis de pistas incluyen el código de FFmpeg en la pantalla. La compatibilidad con el disco NTFS de la LG C1 requiere confirmación en el televisor.

SHA-256 del IPK `__IPK_SHA256__`.
