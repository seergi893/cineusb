# CineUSB 0.10.0

CineUSB abre los discos USB en una cuadrícula para el mando. Pulsa OK para entrar en una carpeta o reproducir un vídeo con los controles integrados de PlxNative. Pulsa Atrás para volver a la carpeta.

En televisores con Homebrew Channel y root, CineUSB puede preparar montajes de solo lectura para los discos que el aislamiento de webOS oculta. La reproducción y el acceso al disco requieren comprobación en la televisión.

SHA-256 del IPK `__IPK_SHA256__`.
