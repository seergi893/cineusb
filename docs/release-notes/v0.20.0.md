# CineUSB 0.20.0

Elige castellano o català en **Ajustes**. El cambio se aplica al momento y se guarda para la próxima vez.

Con un vídeo seleccionado, sube a **Eliminar archivo**. CineUSB muestra el nombre del archivo antes de pedir confirmación.

Usa **Desconectar USB de forma segura** para expulsar el disco seleccionado. Espera el mensaje de confirmación antes de retirarlo.

SHA-256 del IPK `__IPK_SHA256__`.
