# CineUSB 0.17.0

CineUSB abre los vídeos grandes del disco USB con soporte para archivos de más de 2 GiB en webOS de 32 bits. Esto corrige el error `CommandFailed` que podía aparecer al seleccionar una película.

Para instalar la versión, abre CineUSB en Homebrew Channel y pulsa **Update**.

SHA-256 del IPK `__IPK_SHA256__`.
