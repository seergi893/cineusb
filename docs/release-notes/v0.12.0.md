# CineUSB 0.12.0

CineUSB deja de leer obligatoriamente el último byte de una película antes de abrirla. Esta comprobación previa podía provocar un error de entrada/salida en discos NTFS, especialmente con archivos grandes. Ahora el reproductor inspecciona los datos necesarios mediante su propio lector, sin esta lectura adicional.

El explorador oculta las carpetas de mantenimiento `$RECYCLE.BIN`, `System Volume Information` y `LG Smart TV`, sin borrarlas ni alterar su contenido. Las carpetas personales y los vídeos siguen visibles.

La navegación USB con el mando LG y la detección de discos se mantienen como en 0.11.0.

**Pendiente de comprobar en el televisor:** que el vídeo que fallaba con «Input/output error (os error 5)» se abra y reproduzca correctamente. Si el controlador NTFS devuelve un error de lectura real durante el análisis o la reproducción, este cambio no lo elimina.

SHA-256 del IPK `__IPK_SHA256__`.
