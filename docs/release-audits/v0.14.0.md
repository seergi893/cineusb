# Auditoría de CineUSB 0.14.0

## Device test evidence

La LG OLED C1 del usuario monta `/dev/sdb1` en `/tmp/usb/sdb/sdb1` con el controlador `tntfs`. Una lectura como root de los primeros 4096 bytes de `Crash.mkv` se completó con éxito. En CineUSB 0.13.0, la lectura de ese archivo desde offset 0 devuelve `EIO (5)` tanto usando `pread` como `seek+read`. El proceso `plxnative` se ejecuta bajo el UID 5535, y el montaje `sdb1` no aparece en `/proc/<pid>/mountinfo`; tampoco existe el archivo bajo `/proc/<pid>/root/tmp/usb/sdb/sdb1/PELIS`. La carpeta del puente `/var/palm/jail/com.seergi893.cineusb/tmp/cineusb-volumes` está vacía. El servicio Homebrew responde satisfactoriamente a `id -u` como root con `stdoutString="0\\n"`.

Los datos confirman que los espacios de montaje del sistema y de la app difieren. No demuestran todavía que el servicio pueda montar el puente de forma efectiva desde la aplicación.

## External compatibility reports known at release time

Hay un informe de la LG OLED C1 con root/Homebrew Channel y un volumen NTFS. El explorador funciona; la reproducción permanece sin comprobar tras la presente modificación.

## Compatibility tiers, and what moved

Se prioriza el montaje explícito de solo lectura preparado desde el servicio root; se conserva el montaje visible del jail como alternativa. La reproducción no se considera validada hasta realizar una prueba real con el IPK de esta versión.

## Known issues at release, with provenance

La versión anterior dejaba de intentar reparar el montaje si las carpetas eran visibles, aunque las lecturas de archivos fallasen. La corrección solicita siempre la conciliación del puente de solo lectura durante el escaneo periódico y registra si el servicio lo rechaza. Sigue siendo posible que el firmware impida la propagación de los montajes, que el servicio de Homebrew falle o que persistan errores de lectura de la unidad.

## Deliberately not done

No se modifica el disco, no se cambia `tntfs`, no se repara NTFS, no se concede al proceso acceso root, no se ocultan los fallos del montaje y no se asegura la reproducción sin prueba en la televisión.

## Release configuration

Se actualizan `pkg/appinfo.json`, `ipkroot/ctl/control`, `rust-modules/Cargo.toml` y la entrada propia de `rust-modules/Cargo.lock` a 0.14.0. El paquete se construye con `FLAVOR=stable` y `RELEASE=1`, y mantiene el ID `com.seergi893.cineusb`.
