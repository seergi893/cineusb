# Auditoría de CineUSB 0.15.0

## Device test evidence

La auditoría de la 0.14.0 documenta que root pudo leer el archivo en la LG C1 y que CineUSB recibió EIO desde el primer byte. Falta verificar esta versión con el mismo disco y archivo.

## External compatibility reports known at release time

El usuario sigue viendo el error al identificar el contenedor. Falta el código de retorno de FFmpeg para ese intento concreto.

## Compatibility tiers, and what moved

La compilación comprueba MKV y MP4 con la misma configuración de FFmpeg que se empaqueta, además del intercambio de descriptores y la apertura restringida del helper. La prueba Linux no ejercita el controlador NTFS de la LG.

## Known issues at release, with provenance

El respaldo necesita acceso al servicio root de Homebrew y al socket del proceso. Los fallos al abrir o analizar el contenedor muestran el código de FFmpeg.

## Release configuration

Paquete ARM estable `com.seergi893.cineusb` con los protocolos locales `file` y `fd` de FFmpeg.
