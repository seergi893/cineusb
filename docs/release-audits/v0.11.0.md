# Auditoría de CineUSB 0.11.0

## Device test evidence

La LG OLED C1 del usuario reconoce un volumen NTFS en `/tmp/usb/sda/sda1` con carpetas `PELIS` y `SERIES`. Antes de esta versión, CineUSB mostraba una tarjeta `sda1`, pero no abría el disco con OK; el botón Atrás sí cerraba la aplicación. La corrección de 0.11.0 no se ha comprobado todavía en el dispositivo físico.

La compilación ARM del PR anterior terminó correctamente, pero la validación del paquete 0.11.0 falló por la ausencia de estos documentos. No hay pruebas de navegación, reproducción ni rendimiento realizadas en el televisor con el nuevo IPK.

## External compatibility reports known at release time

El informe disponible procede de la prueba de CineUSB en una LG OLED C1 con Homebrew Channel y root. El sistema webOS montaba la partición como NTFS y el reproductor integrado del televisor podía explorarla. No se dispone de una confirmación externa de funcionamiento de la versión 0.11.0.

## Compatibility tiers, and what moved

La existencia del montaje NTFS en el sistema está comprobada en ese televisor. La lectura desde el aislamiento de CineUSB, el enfoque del mando y la reproducción pertenecen a un nivel todavía no validado. Los nuevos controles de teclado y puntero requieren pruebas físicas; superar la compilación no cambia su nivel de compatibilidad.

## Known issues at release, with provenance

La implementación mantiene una cuadrícula USB separada del sistema completo de pantallas de PlxNative, de modo que no se puede afirmar paridad de navegación o fluidez. La selección de la tarjeta USB sin apertura se observó en el televisor antes de esta corrección; falta comprobar si el cambio resuelve todos los eventos del mando.

La publicación anterior reutilizó el número de versión 0.10.0: se generaron borradores, mientras la release pública seguía enlazada al código anterior. Esta versión cambia los metadatos de paquete a 0.11.0 para producir un IPK distinguible.

## Deliberately not done

No se han incorporado el navegador completo ni el motor de foco de PlxNative a la interfaz USB. No se ha modificado el contenido del disco ni se garantiza soporte para todos los sistemas de archivos. No se declara superada ninguna prueba de reproducción en una LG física.

## Release configuration

GitHub Actions compila para ARM con `FLAVOR=stable` y `RELEASE=1` y publica `com.seergi893.cineusb`. La versión del paquete, el archivo de control y la versión Cargo se actualizan conjuntamente a 0.11.0. No se incluyen credenciales Plex ni dependencia de un servidor Plex en el flujo del explorador USB.
